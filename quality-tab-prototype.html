📝 Заметки к прототипу
  • Высота бара = всего merged PR в бакете (абсолютная шкала, ось слева). Это даёт сразу две информации в одном виде: объём работы + доля проблемных.
  • Стек снизу вверх: P1 (красный) → P2-only (жёлтый) → чистые PR (голубой). Глаз цепляется за красное внизу — там самое важное; чистый объём наверху как "фон/итог".
  • Worst-wins для overlapping PR: PR с одновременно P1+P2 учитывается в P1 (чтобы сумма сегментов точно равнялась total PR без двойного счёта).
  • % грязных PR = (P1 + P2-only) / total — заголовочная цифра в правом блоке KPI и в карточке проекта.
  • Tooltip: дата периода, всего PR, чистых, P1, P2-only, % грязных.
  • Пустые проекты: если за период < 3 merged PR — карточка серая (см. Beer_bot).
  • Цвета: --v4-p1 #EF4444, --v4-p2 #F79009, --v4-clean-soft #93C5FD (lighter --v4-accent-500).
  • Синхронизация: раз в сутки в 03:00 по Бали (UTC+8 → 19:00 UTC). Открываешь дашборд утром — видишь уже агрегированные данные за вчера. Архитектура обсуждается отдельно (см. ответ ниже).
